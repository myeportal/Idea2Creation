# SMMJV Review Build

Review-only affiliate launch package for **The Selfmademoney Plan** tailored for **JVZoo** promotion.

This folder is a safe review copy inside `test/` so the main `smmjv/` package can remain unchanged while you evaluate refinements.

## Included
- `index.html` — contest-style partner-facing JV page website
- `bonus-page.html` — affiliate bonus page template
- `affiliate-thank-you.html` — affiliate thank-you / approval queue page
- `affiliate_swipes.md` — email subjects, promo copy, and short-form swipes
- `jvzoo_listing_copy.md` — listing-ready copy blocks and positioning notes
- `vendor_email_assets.md` — affiliate approval and JV invite email templates
- `launch_package_notes.md` — launch strategy, positioning, placeholders, and suggested setup notes
- `PACKAGE_CHECKLIST.md` — final prep / handoff checklist
- `assets/` — reused imagery from the main Selfmademoney Plan offer
